# Single-page funnel — design mockup

A static **layout preview** for a single-page counselling and coaching website.

This is a design mockup shared with a client for review. It is **not a live
website**:

- No form on the page submits anywhere. There is no `action`, no backend, no
  database, and no analytics or tracking of any kind.
- No data is collected, stored or transmitted.
- The page is `noindex, nofollow`.
- Every name, price, qualification, registration number and testimonial on the
  page is a bracketed placeholder written by the developer, e.g. `[BACP / UKCP /
  NCPS]`, `£[00]`, `[Client initials]`. None of it is a factual claim about any
  real person or practice.

Built as plain HTML and CSS in a single file. The production build will be
WordPress on the client's own hosting.
